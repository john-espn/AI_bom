# 铅笔制造 AI-BOM 智能体 MVP

这是基于删减版 SRS 构建的私有部署演示应用，覆盖以下闭环：

`登录 → 上传订单 → 解析/确认字段 → 检索历史 BOM → 生成 EBOM 草稿 → 人工修改与确认 → 批量派生 → 记录和审计查询`

## 本地启动

建议使用 Python 3.11 或更新版本。

```bash
python3 -m pip install -r requirements.txt
python3 -m app.seed
python3 -m uvicorn app.main:app --reload --port 8000
```

浏览器访问：<http://127.0.0.1:8000>

演示账号：

| 账号 | 密码 | 角色 | 主要权限 |
| --- | --- | --- | --- |
| `buyer` | `demo123` | 采购人员 | 上传、解析、生成、编辑、批量派生 |
| `engineer` | `demo123` | 工艺/技术人员 | 复核、编辑、确认 BOM |
| `admin` | `demo123` | 系统管理员 | 全部权限、知识库导入、审计查看 |

> 账号密码为演示数据，数据库中以明文保存，仅用于本地 MVP。生产部署必须改用密码哈希、HTTPS、安全的 `SESSION_SECRET` 和正式身份认证。

## 演示步骤

1. 使用 `buyer` 登录，在“上传订单”选择 `app/data/demo_orders/order_pencil_001.txt`。
2. 检查解析字段、置信度和历史 BOM 候选，确认字段后生成 EBOM。
3. 使用 `engineer` 登录，对 BOM 行做必要修改并确认。
4. 使用 `buyer` 或 `admin` 打开“批量派生”，选择已确认 BOM，将以下内容粘贴到变体输入框：

```text
PO-2026-0916-002,7.0mm HB 六角杆,RED-01,金色烫印;白色橡皮头;12支盒彩盒
PO-2026-0916-003,7.0mm HB 六角杆,GREEN-03,银色烫印;白色橡皮头;12支盒彩盒
PO-2026-0916-004,8.0mm 2B 圆杆,BLACK-01,未知辅料
```

5. 查看批量任务结果。前两项基于历史证据生成，规格变化项进入人工复核。
6. 在“生成记录”按订单号、色号和状态查询；管理员可在“系统管理”查看审计日志。

## 支持范围

- TXT 与文本型 DOCX 订单解析。
- 单一 `7.0mm HB 六角杆` 铅笔产品族的演示历史 BOM。
- 规格、系列、色号及辅料重叠度检索。
- 可追溯 EBOM 草稿、字段级来源、差异解释和置信度。
- 人工修改留痕，技术人员/管理员最终确认。
- CSV 历史 BOM 导入。

## 治理边界

该应用是 L1 辅助决策演示。它不会自动下单、修改物料主数据、下发生产或代替人工审批。缺少历史依据、规格变化、字段冲突或低置信度结果均进入人工复核。
